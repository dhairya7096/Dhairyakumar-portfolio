# Dhairyakumar Patel — React Portfolio

A premium dark developer portfolio built with React, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Personal links to update

Open `src/main.jsx` and replace:

- `LINKEDIN` with your verified public LinkedIn URL.
- `EMAIL` with your preferred contact email, e.g. `mailto:you@example.com`.

GitHub is already connected to `https://github.com/dhairya7096`.

## Notes
